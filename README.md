# Welder Bid Tracker

AI-powered bidding and job tracking app for independent welder fabricators.

## Features
- Fast job quoting with material cost lookup
- Job tracking and progress logging
- Simple invoicing
- AI assistance for pricing and scheduling

## Tech Stack
- React Native for cross-platform mobile
- Node.js backend
- Simple local database for starters

## Getting Started

Clone the repo and follow the instructions in the code.
